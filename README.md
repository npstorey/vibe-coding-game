# Vibe Coding Simulator

A simulation game where players use AI-assisted development to build digital products in a minimalist 3D environment.

## Description

Vibe Coding Simulator is a single-player simulation game where you play as a solopreneur using "vibe coding" (AI-assisted development) to build various digital products. The game is presented in a minimalist 3D environment using Three.js that depicts a home office.

Players interact with an in-game computer to:
- Manage coding projects
- Track finances
- Improve skills
- Perform AI-driven coding tasks
- Research new techniques
- Upgrade hardware and AI models

## Features

- **3D Environment**: A minimalist home office with a desk, computer, and other office elements
- **Time & Resource Management**: Balance work on multiple projects with limited daily "action" resources
- **AI-Assisted Coding**: Simulated unpredictability in project outcomes based on your prompts, skills, and AI model quality
- **Skill & Tech Progression**: Unlock advanced AI models, hardware upgrades, and new prompting techniques
- **Market Trends**: Periodic hype cycles affecting project profitability and success

## Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Safari)
- Node.js and npm (for development)

### Installation

1. Clone the repository:
```
git clone https://github.com/your-username/vibe-coding-simulator.git
```

2. Navigate to the project directory:
```
cd vibe-coding-simulator
```

3. Install dependencies:
```
npm install
```

4. Start the development server:
```
npm start
```

5. Open your browser and visit `http://localhost:5173`

## How to Play

1. **Start the Game**: Click on the computer monitor in the 3D scene to open the game interface
2. **Start a Project**: Go to "Manage Projects" and start a new project
3. **Code Your Project**: Write prompts for the AI assistant to generate code
4. **Improve Skills**: Research new techniques and improve your coding/prompt engineering skills
5. **Upgrade**: As you earn money, upgrade your AI models and hardware
6. **Manage Resources**: Each day gives you 8 time blocks - use them wisely!
